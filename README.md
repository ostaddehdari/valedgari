# والدیار — سامانه راهنمای والد و نوجوان

نسخه اجرایی فاز اول والدیار با Flask، SQLite، jQuery، Bootstrap RTL، Font Awesome، Animate.css و فونت وزیرمتن.

## قابلیت‌های موجود

- لندینگ‌پیج یک‌صفحه‌ای، فارسی، واکنش‌گرا و دارای حرکت‌های کنترل‌شده
- ثبت‌نام و ورود با موبایل و رمز عبور، بدون OTP در نسخه فعلی
- هش‌کردن رمز با scrypt، CSRF، کوکی HttpOnly و هدرهای امنیتی
- داشبورد والد و پرونده مستقل برای چند فرزند
- سنجش خط پایه والدگری و ذخیره نتیجه برای فرزند فعال
- ماژول مهارت‌های والدگری و ثبت پیشرفت مستقل هر فرزند
- موتور ۲۵ موقعیت × ۵ سطح با روایت‌های نامحدود و چهار واکنش بامریند
- پنل مدیر، آمار پایه، کاربران، استودیو موقعیت و فرم‌ساز پویا
- انتخاب بدون افشای سبک، تحلیل پیامد و مهارت، تلاش مجدد و جلوگیری از تکرار روایت
- قرارداد JSON `valedgari-scenario-v1` با Import پیش‌نویس و Export نسخه‌دار
- فرم‌ساز حرفه‌ای سه‌ستونه با ۵۴ نوع فیلد، منطق شرطی، صفحه‌بندی و پیش‌نمایش زنده
- قرارداد JSON هوش مصنوعی `ensha-assessment-v2` با Import امن Draft و Export نسخه‌دار
- امتیازدهی وزنی/معکوس/زیرمقیاس، گردش تأیید علمی، تخصیص و گزارش CSV فرم‌ها
- کاتالوگ مهارت با سطح، سبک فرزندپروری، موقعیت و پیش‌نیاز
- دوره‌های رایگان و پولی با آرشیو عمومی، صفحه معرفی و اسلایدر Drag/Swipe لندینگ
- دوره‌ساز چندفصلی Drag/Drop با متن، ویدئو، صوت، فایل، لینک و آزمون متصل به فرم‌ساز
- ثبت‌نام رایگان، دوره‌های من، کلاس مجازی و پیشرفت مستقل برای هر والد/فرزند
- پنل مدیر دوره، کپی، نسخه‌بندی، انتشار، بایگانی و مشاهده دانشجویان
- سفارش و فاکتور نسخه‌دار با Snapshot قیمت و اعمال حمایت ۷۰/۳۰ سازمان
- زرین‌پال Sandbox/Production با Authority، Verify و جلوگیری از پرداخت/Callback تکراری
- تاریخچه مالی والد، فاکتور چاپی/PDF، بازپرداخت و کنترل مالکیت رسید
- تنظیم رمز‌شده Merchant ID و API Token از پنل مدیر
- IPPanel با Patternهای رویدادی، Outbox، Retry و فرمان پردازش صف
- گزارش فروش، سهم سازمان، مغایرت مالی و CSV مدیر
- پروژه‌های سازمانی با کد حمایت، سیاست ۷۰/۳۰ یا مبلغ ثابت
- کنترل بودجه، ظرفیت، اعتبار، سهم والد/سازمان و دفتر مالی قابل حسابرسی
- گزارش CSV پروژه و چرخه رزرو، پرداخت والد، تسویه، لغو و بازپرداخت
- موتور نسخه‌بندی ابزار بامریند با دروازه انتشار علمی
- ورود JSON سؤال‌ها، سؤال معکوس، وزن و نمره سه‌بُعدی
- نمای مستقل هر فرزند: نقاط قوت، محرک‌ها، آرام‌سازی، اولویت‌ها و رابطه
- تاریخچه بازسنجی و خلاصه قابل اقدام بدون ادعای تشخیص بالینی
- موتور شخصی‌سازی قاعده‌محور بر اساس فرزند، شدت، سبک والد و نتیجه اقدام قبلی
- توضیح دلیل پیشنهاد، تمرین خانه، رفتار نامناسب و اتصال به مهارت مرتبط
- پنل مدیر قواعد با اولویت، نسخه، انتشار و بایگانی
- ثبت نتیجه واقعی و تغییر پیشنهاد بعدی با حفظ snapshot تاریخی
- taxonomy شش‌حوزه‌ای مهارت‌های والدگری و ریزدرس‌های نسخه‌بندی‌شده
- برنامه هفت‌روزه مستقل برای هر فرزند و «اقدام امروز»
- مسیر ترتیبی یادگیری، مشاهده، تمرین موقعیت، اقدام خانه، ترمیم و مرور
- ثبت یادداشت و اطمینان هر قدم و مرور نتیجه پایان هفته
- پنل مدیر برای حوزه‌ها، ریزدرس‌ها و آمار مسیر آموزشی
- همراه هوشمند کنترل‌شده و مستقل برای هر فرزند
- پاسخ‌های منبع‌دار از برنامه، ریزدرس، پیشنهاد و قاعده منتشرشده
- مرز صریح برای تشخیص، تجویز، درخواست خارج از دامنه و تلاش دورزدن
- پروتکل‌های نسخه‌بندی‌شده بحران و مرکز نظارت مدیر
- ثبت بازخورد والد و ممیزی نوع تصمیم و منابع پاسخ
- سازگار با اجرا زیر مسیر `/valedgari` از طریق `X-Forwarded-Prefix`
- تست‌های خودکار و فایل‌های آماده Gunicorn، systemd و Nginx
- قیف فعال‌سازی و داشبورد اثربخشی آموزشی غیرتشخیصی
- گزارش سازمانی ناشناس با حداقل گروه ۵ نفره
- مرکز حریم خصوصی، رضایت نسخه‌دار و حذف ممیزی‌شده پرونده فرزند
- نقش مستقل ناظر علمی و تأیید متصل به snapshot نسخه محتوا
- readiness دیتابیس، بکاپ روزانه و مانور بازیابی هفتگی

## اجرای محلی

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SECRET_KEY="یک-کلید-تصادفی-طولانی"
flask --app wsgi:app create-admin
flask --app wsgi:app run --debug
```

سپس `http://127.0.0.1:5000` را باز کنید.

## تست

```bash
pytest -q
```
