# والدیار — سامانه راهنمای والد و نوجوان

نسخه اجرایی فاز اول والدیار با Flask، SQLite، jQuery، Bootstrap RTL، Font Awesome، Animate.css و فونت وزیرمتن.

## قابلیت‌های موجود

- لندینگ‌پیج یک‌صفحه‌ای، فارسی، واکنش‌گرا و دارای حرکت‌های کنترل‌شده
- ثبت‌نام و ورود با موبایل و رمز عبور، بدون OTP در نسخه فعلی
- هش‌کردن رمز با scrypt، CSRF، کوکی HttpOnly و هدرهای امنیتی
- داشبورد والد و پرونده مستقل برای چند فرزند
- سنجش خط پایه والدگری و ذخیره نتیجه برای فرزند فعال
- ماژول مهارت‌های والدگری و ثبت پیشرفت مستقل هر فرزند
- راهنمای موقعیت‌ها با ۵ سطح شدت
- پنل مدیر، آمار پایه، کاربران، درخت مسیر و فرم‌ساز پویا
- سازگار با اجرا زیر مسیر `/valedgari` از طریق `X-Forwarded-Prefix`
- تست‌های خودکار و فایل‌های آماده Gunicorn، systemd و Nginx

## اجرای محلی

```bash
python3 -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
export SECRET_KEY="یک-کلید-تصادفی-طولانی"
flask --app wsgi:app create-admin
flask --app wsgi:app run --debug
```

سپس `http://127.0.0.1:5000` را باز کنید.

## تست

```bash
pytest -q
```
