# استیج ۲ — بامریند و نمای مستقل هر فرزند

این سند تحویل فنی استیج ۲ والدیار را ثبت می‌کند.

## اصل علمی

سامانه بین «آمادگی فنی اجرای ابزار» و «اعتبار علمی محتوای ابزار» تفکیک می‌کند. موتور بامریند کامل است، اما تا وقتی نسخه، منبع، ترجمه، مجوز و سؤال‌های مصوب وارد نشده باشند، والد هیچ آزمونی با عنوان استاندارد نمی‌بیند.

## اجزای بامریند

- `AssessmentInstrument`: چارچوب، عنوان، نسخه، وضعیت، منبع، مجوز، محدودیت تفسیر و schema نمره‌گذاری
- `AssessmentQuestion`: کد، متن، بُعد، وزن، سؤال معکوس و الزام پاسخ
- `ParentingStyleAssessment`: پاسخ‌ها، امتیاز هر بُعد، نتیجه غالب، تفسیر، فرزند و نسخه ابزار

ابعاد فعال نسخه نخست:

- مقتدرانه (`authoritative`)
- مستبدانه (`authoritarian`)
- سهل‌گیرانه (`permissive`)

این ساختار به‌معنای تأیید یک پرسش‌نامه خاص نیست. متن و نمره‌گذاری نهایی باید با نسخه مصوب مسئول علمی تطبیق داده شود.

## دروازه انتشار علمی

مدیر فقط زمانی می‌تواند ابزار را منتشر کند که:

1. منبع دقیق نسخه ثبت شده باشد.
2. وضعیت مجوز و ترجمه ثبت شده باشد.
3. حداقل سؤال معتبر وجود داشته باشد.
4. هر سه بُعد سؤال داشته باشند.
5. نسخه مشخص باشد.

هر تغییر در مشخصات یا سؤال‌ها، ابزار را به وضعیت بازبینی برمی‌گرداند. نتیجه‌های قبلی با نسخه زمان اجرای خود حفظ می‌شوند.

## قالب ورود سؤال

```json
[
  {
    "code": "Q01",
    "text": "متن مصوب سؤال",
    "dimension": "authoritative",
    "weight": 1,
    "reverse_score": false,
    "is_required": true
  }
]
```

## موتور نمره‌گذاری

- مقیاس پیش‌فرض ۱ تا ۵ است.
- سؤال معکوس پیش از محاسبه برگردان می‌شود.
- میانگین وزنی هر بُعد به درصد صفر تا صد تبدیل می‌شود.
- بالاترین بُعد همراه با توضیح محدود و غیرتشخیصی نمایش داده می‌شود.
- پاسخ خام، امتیازها و نسخه ابزار در هر اجرا ذخیره می‌شوند.

اگر نسخه علمی مصوب فرمول متفاوتی داشته باشد، schema و موتور باید بر همان اساس تنظیم شوند؛ انتشار پیش از این تطبیق مجاز نیست.

## نمای فرزند

دو فرم داخلی و آموزشی ساخته شده است:

### شناخت اولیه

- شدت هیجان، سازگاری، حساسیت محیطی، گفت‌وگو، پشتکار و راحتی اجتماعی
- نقاط قوت
- محرک‌های تنش
- راه‌های مؤثر آرام‌شدن
- الگوی خشم یا فشار
- اولویت‌های سه ماه آینده
- یادداشت والد

### رابطه والد–فرزند

هشت گزاره درباره تشخیص نشانه‌های تنش، زمان گفت‌وگو، مرزها، مکث والد، شنیده‌شدن، ترمیم رابطه، شناخت محرک‌ها و توافق کوچک.

این فرم پرسش‌نامه بامریند یا ابزار تشخیصی نیست و در رابط نیز به‌صراحت همین محدودیت نمایش داده می‌شود.

## نسخه‌بندی و جداسازی

- هر ذخیره یک Snapshot جدید می‌سازد.
- نسخه‌های شناخت اولیه و رابطه جدا هستند.
- همه داده‌ها هم‌زمان به والد و فرزند فعال متصل‌اند.
- جابه‌جایی از زهرا به علی هیچ نتیجه یا خلاصه‌ای را منتقل نمی‌کند.
- داشبورد تکمیل سه قدم شناخت، رابطه و سبک والدگری را جداگانه نشان می‌دهد.

## معیارهای پذیرش خودکار

- جلوگیری از انتشار ابزار بدون منبع، مجوز و سؤال
- ورود معتبر JSON و پوشش سه بُعد
- محاسبه سؤال مستقیم و معکوس با وزن
- اتصال نتیجه به فرزند فعال و نسخه ابزار
- ساخت نسخه‌های متوالی نمای فرزند
- جداسازی کامل دو فرزند یک والد
- نمایش امن حالت «در انتظار تأیید علمی»

## مرز استیج

استیج ۲ داده لازم برای شخصی‌سازی را می‌سازد. استفاده از این داده برای انتخاب توصیه متفاوت، نمایش «چرا این پیشنهاد؟» و ثبت نتیجه اقدام، موضوع استیج ۳ است.
