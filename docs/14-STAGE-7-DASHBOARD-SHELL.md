# تحویل استیج ۷ — پوسته نقش‌محور داشبورد

تاریخ تحویل: ۸ آبان ۱۴۰۵ (۳۰ اکتبر ۲۰۲۶)

استیج ۷ با هدف حذف منوی افقی عملیاتی، ساخت سایدبار متناسب با نقش و رفع خطای اسکرول مودال پروژه سازمانی تکمیل شد. این استیج تغییر مدل داده یا Migration ندارد.

## نتیجه ۱۰ ورک

| ورک | وضعیت | خروجی پیاده‌سازی‌شده |
|---|---|---|
| 7.1 | تکمیل | `modal-content > form` به Flex محدودشده تبدیل شد؛ هدر و فوتر ثابت و بدنه دارای اسکرول مستقل است. |
| 7.2 | تکمیل | پوسته مشترک داشبورد شامل سایدبار، Topbar، محتوای اصلی، پیام‌ها و Footer ساخته شد. |
| 7.3 | تکمیل | مسیرهای مدیریت در چهار گروه نمای کلی، سازمان/کاربر، سنجش/محتوا و نظارت/عملیات قرار گرفتند. |
| 7.4 | تکمیل | مسیرهای فعلی والد در گروه‌های شروع، پرونده خانواده، مسیر رشد و حساب/پشتیبانی قرار گرفتند. مسیرهای دوره و مالی در استیج‌های ۱۱ و ۱۲ به همین گروه افزوده می‌شوند. |
| 7.5 | تکمیل | ناظر علمی فقط سایدبار مجازِ کارتابل بررسی را می‌بیند. |
| 7.6 | تکمیل | هدر فقط بازکننده سایدبار، عنوان پنل و منوی حساب را نگه می‌دارد. |
| 7.7 | تکمیل | صفحه `/auth/profile`، ویرایش نام، لینک پروفایل و خروج POST دارای CSRF اضافه شد. |
| 7.8 | تکمیل | سایدبار دسکتاپ جمع‌شونده با ذخیره وضعیت و سایدبار موبایل Offcanvas با Overlay پیاده شد. |
| 7.9 | تکمیل | `aria-current`، Skip Link، حالت فعال، برچسب‌های ARIA، بستن با Escape و بازگرداندن Focus اضافه شد. |
| 7.10 | تکمیل | چهار آزمون جدید برای نقش‌ها، مسیر فعال، پروفایل و قرارداد اسکرول مودال اضافه و کل ۴۱ آزمون عبور کرد. |

## رفتار در اندازه‌های مختلف

- دسکتاپ: سایدبار ۲۸۰ پیکسل و حالت جمع‌شده ۸۸ پیکسل است؛ انتخاب کاربر در `localStorage` حفظ می‌شود.
- تبلت و موبایل: زیر عرض ۹۹۲ پیکسل، محتوا تمام‌عرض و سایدبار به‌صورت Offcanvas نمایش داده می‌شود.
- موبایل کوچک: متن حساب در هدر پنهان می‌شود اما آواتار، پروفایل و خروج در دسترس می‌مانند.
- چاپ: سایدبار، هدر داشبورد و کنترل‌های ناوبری چاپ نمی‌شوند.

## کنترل‌های پذیرش

```bash
python -m compileall app
node --check app/static/js/app.js
pytest -q
```

نتیجه تحویل: `41 passed`. دو هشدار موجود مربوط به API قدیمی زمان در وابستگی Flask-Login است و شکست آزمون محسوب نمی‌شود.

## فایل‌های اصلی

- `app/templates/base.html`: پوسته عمومی/داشبورد و هدر حساب
- `app/templates/_dashboard_sidebar.html`: منوی نقش‌محور
- `app/templates/auth/profile.html`: پروفایل پایه کاربر
- `app/static/css/app.css`: چیدمان Responsive و اصلاح مودال
- `app/static/js/app.js`: مدیریت وضعیت سایدبار، Escape و ذخیره ترجیح
- `app/auth.py`: مسیر امن پروفایل
- `tests/test_app.py`: آزمون‌های رگرسیون استیج ۷

## مرز این استیج

پروفایل این مرحله فقط اطلاعات پایه حساب را پوشش می‌دهد. پروفایل‌های کامل سازمان، والد/سرپرست و فرزند، فیلدهای پویا و روابط خانوادگی طبق نقشه در استیج ۹ ساخته می‌شوند. جداسازی سازمان از قرارداد، حذف امن سازمان خالی و بایگانی قرارداد مربوط به استیج ۸ است.
