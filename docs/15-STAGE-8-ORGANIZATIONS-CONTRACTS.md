# تحویل استیج ۸ — سازمان، قرارداد و پوشش سازمانی

تاریخ تحویل: ۸ آبان ۱۴۰۵ (۳۰ اکتبر ۲۰۲۶)

در این استیج «سازمان»، «قرارداد» و «طرح حمایت» از یکدیگر جدا شدند. سازمان اکنون پرونده‌ای پایدار است، قرارداد چرخه زمانی و مالی مستقل دارد و سیاست ۷۰/۳۰ به‌صورت یک طرح اجرایی زیر قرارداد قرار می‌گیرد.

## نتیجه ۱۰ ورک

| ورک | وضعیت | خروجی پیاده‌سازی‌شده |
|---|---|---|
| 8.1 | تکمیل | صفحه مستقل `/admin/organizations` با فهرست کارتی، جست‌وجو، فیلتر وضعیت و مودال افزودن سازمان ساخته شد. |
| 8.2 | تکمیل | پروفایل سازمان شامل اطلاعات حقوقی، تماس، نشانی، وب‌سایت، لوگو و اتصال به یک فرم از فرم‌ساز قابل ویرایش است. |
| 8.3 | تکمیل | سازمان بدون عضو، ذی‌نفع، تراکنش یا مصرف با ورود نام دقیق حذف می‌شود؛ قراردادهای بدون مصرف مانع حذف نیستند. |
| 8.4 | تکمیل | مدل مستقل قرارداد با شماره یکتا، متن، شرایط، تعهدها، بازه اجرا، مبلغ کل، پرداخت‌شده، خدمات و فایل مرجع ایجاد شد. |
| 8.5 | تکمیل | قراردادهای هر سازمان در تب مستقل ساخته، ویرایش، نسخه‌بندی، پایان یا بایگانی می‌شوند. |
| 8.6 | تکمیل | درصد/مبلغ ثابت، سقف خانواده، ظرفیت، بودجه، کد و خدمات مشمول در قالب طرح حمایت زیر قرارداد قرار گرفتند. |
| 8.7 | تکمیل | والد، فرزند یا کل خانواده با بازه زمانی و وضعیت مستقل به قرارداد متصل می‌شود. |
| 8.8 | تکمیل | تعداد ذی‌نفع، فرزند، مصرف خدمت، تعهد طرح‌ها، مبلغ کل و پرداخت‌شده در لحظه محاسبه و نمایش داده می‌شود. |
| 8.9 | تکمیل | بایگانی قرارداد، طرح‌های فعال آن را می‌بندد اما سوابق، اعضا و گزارش‌ها را نگه می‌دارد. |
| 8.10 | تکمیل | گزارش CSV سازمان و Audit ساخت، ویرایش، حذف، قرارداد، ذی‌نفع، طرح و خروجی گزارش اضافه شد. |

## مدل داده

- `Organization`: پرونده پایدار سازمان و اطلاعات فرم پویا
- `OrganizationContract`: قرارداد مستقل، نسخه‌دار و بایگانی‌پذیر
- `ContractBeneficiary`: اتصال قرارداد به والد، فرزند یا خانواده
- `SponsoredProject`: طرح اجرایی، کد استفاده و سیاست حمایت
- `OrganizationAuditLog`: ردپای تغییرات سازمان و قرارداد حتی پس از حذف امن سازمان

رابطه اصلی:

```text
سازمان ← چند قرارداد ← چند ذی‌نفع
                   ← چند طرح حمایت ← عضویت و تخصیص مالی
```

## مسیرهای مدیریتی

| مسیر | کاربرد |
|---|---|
| `/admin/organizations` | فهرست، جست‌وجو و افزودن سازمان |
| `/admin/organizations/<id>` | پروفایل، قراردادها، فرزندان و Audit سازمان |
| `/admin/contracts/<id>` | متن قرارداد، پرداخت، ذی‌نفعان، طرح‌ها و بایگانی |
| `/admin/projects` | فهرست طرح‌های حمایت و کدهای پرداخت سهمی |
| `/admin/organizations/<id>/export.csv` | گزارش والد، فرزند، قرارداد و مالی سازمان |

## سازگاری داده

مسیر قدیمی ساخت پروژه برای داده‌ها و کلاینت‌های قبلی حفظ شده است. اگر فرم قدیمی ارسال شود، یک قرارداد انتقالی با پیشوند `LEGACY-` ساخته می‌شود؛ رابط جدید دیگر سازمان و قرارداد را هم‌زمان نمی‌سازد.
