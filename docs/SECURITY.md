# امنیت و حریم خصوصی

## وضعیت نسخه فعلی

- رمزها با `scrypt` هش می‌شوند و هرگز به‌صورت متن ساده ذخیره نمی‌شوند.
- فرم‌های تغییر وضعیت CSRF دارند.
- نقش مدیر و والد جداست.
- مالکیت فرزند در تمام مسیرهای والد کنترل می‌شود.
- کوکی نشست HttpOnly و SameSite=Lax است؛ در production فقط روی HTTPS ارسال می‌شود.
- هدرهای CSP، frame، referrer و permissions فعال‌اند.
- فایل دیتابیس و `.env` در Git نادیده گرفته می‌شوند.

## تصمیم آگاهانه درباره OTP

طبق دامنه فعلی، ثبت‌نام کد تأیید ندارد. بنابراین مالکیت واقعی شماره موبایل اثبات نمی‌شود. پیش از فعال‌کردن بازیابی خودکار رمز، پیامک یا روش احراز قابل اعتماد باید اضافه شود. تا آن زمان بازیابی رمز فقط با فرآیند پشتیبانی کنترل‌شده انجام شود.

## موارد لازم پیش از انتشار عمومی

- اجبار HTTPS و HSTS در Nginx
- rate limit برای login و register
- سیاست رمز قوی‌تر و بررسی رمزهای افشاشده
- ثبت رویداد امنیتی بدون ذخیره رمز یا محتوای حساس
- تست نفوذ مسیرهای IDOR، CSRF، XSS و session fixation
- تعیین دوره نگهداری و حذف داده کودک
- رضایت‌نامه و متن حریم خصوصی فارسی
- بکاپ رمزگذاری‌شده و کنترل دسترسی فایل SQLite
