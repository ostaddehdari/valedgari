# استیج ۱۳ — موتور موقعیت‌های ۲۵×۵ و روایت‌های چهارسبکی

## نتیجه

استیج ۱۳، درخت ساده پیشین را بدون حذف سازگاری آن به یک موتور محتوای نسخه‌دار تبدیل می‌کند. کاتالوگ ۲۵ موقعیت، پنج سطح استاندارد بحران، چهار سبک پایه بامریند، روایت‌های نامحدود، واکنش‌ها، پیامدها، مهارت‌ها و تاریخچه تلاش اکنون موجودیت‌های مستقل دارند.

## ورک‌های تحویل‌شده

| ورک | تحویل |

| 13.1 | کاتالوگ ۲۵ موقعیت با عنوان، شرح، حوزه، مهارت هدف، وضعیت و ترتیب |
| 13.2 | پنج سطح «سطحی، آشکار، پیش‌رونده، قوی/خطرناک و عمیق» با رنگ و مظاهر رفتاری |

| 13.5 | چهار واکنش اجباری برای هر روایت و جلوگیری از انتشار روایت ناقص |

| 13.9 | استودیو محتوا، فیلتر ۲۵×۵، کپی، Import/Export و گردش تأیید علمی |
| 13.10 | جلوگیری از تکرار تا اتمام مخزن، امتیاز مهارتی، تاریخچه و تست ماتریس ۲۵×۵×۴ |

## مدل داده

- `ScenarioTopicProfile`: متادیتای کاتالوگ، مستقل از جدول قدیمی موضوع‌ها
- `CrisisLevelDefinition`: تعریف مرجع پنج سطح بحران
- `ParentingStyleDefinition`: کاتالوگ سبک‌های قابل‌گسترش
- `ScenarioNarrative`: روایت نسخه‌دار با وضعیت Draft/Review/Published/Archived
- `ScenarioReaction`: واکنش سبک، مهارت‌ها، پیامدها، راهنمای تلاش و امتیاز
- `ScenarioNarrativeAttempt`: انتخاب والد، ترتیب گزینه‌ها، امتیاز و زنجیره تلاش مجدد

جداول جدید از جداول قدیمی جدا هستند تا Migration یکپارچه و برگشت‌پذیر در استیج ۱۵ انجام شود.

## قرارداد JSON

شناسه قرارداد:

```json
{"contract": "valedgari-scenario-v1", "narratives": []}
```

Import می‌تواند چند روایت را یکجا بسازد، اما همه موارد را عمداً در وضعیت `draft` قرار می‌دهد. JSON نمی‌تواند محتوای علمی را مستقیم منتشر کند.

## انتشار علمی

- روایت ناقص با کمتر از چهار واکنش پایه منتشر نمی‌شود.
- متن واکنش، پیامد کوتاه‌مدت، پیامد بلندمدت و راهنمای تلاش مجدد برای هر سبک اجباری است.
- تأیید علمی به اثرانگشت همان نسخه متصل است.
- در Production، تغییر متن یا نسخه، تأیید قبلی را نامعتبر می‌کند.
- در خطر فوری، رابط همچنان ارجاع حضوری/امدادی را مقدم بر آموزش عمومی نشان می‌دهد.

## تجربه والد

نام سبک‌ها پیش از انتخاب دیده نمی‌شود. پس از پاسخ، والد این موارد را می‌بیند:

- سبک نزدیک‌تر به انتخاب
- امتیاز آموزشی همان واکنش
- مهارت‌های حاضر و غایب
- پیامد کوتاه‌مدت و بلندمدت
- راهنمای تلاش مجدد
- روند تجمیعی مهارت‌ها

انتخاب‌ها بین فرزندان و والد‌ها جدا هستند و شناسه تلاش با مالکیت خانواده کنترل می‌شود.
